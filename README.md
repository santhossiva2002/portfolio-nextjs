# Personal Portfolio Dashboard

A modern, responsive personal portfolio dashboard built with Next.js, Tailwind CSS, and Framer Motion. This project showcases my professional experience, skills, and achievements in an interactive and visually appealing way.

## 🚀 Features

- **Responsive Design**: Fully responsive layout that works seamlessly across all devices
- **Dark Mode Support**: Built-in dark mode with system preference detection
- **Smooth Animations**: Engaging animations using Framer Motion
- **Modern UI**: Clean and professional design with glass-morphism effects
- **Interactive Sections**: 
  - Profile & Contact Information
  - Technical Skills
  - Education Timeline
  - Project Showcase
  - Professional Experience
  - Achievements
  - Vision & Goals

## 🛠️ Tech Stack

- **Framework**: Next.js 13 with App Router
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Theme**: Next-themes for dark mode
- **UI Components**: Shadcn/ui
